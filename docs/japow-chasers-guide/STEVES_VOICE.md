# Steves voice — one sheet

Use this when editing [DRAFT_v1_copyedited.md](./DRAFT_v1_copyedited.md) and `docs/research/inbox/full-guide-preview/index.html`. Same facts. Same yen. Same URLs. Same `[VERIFY 2026–27]` *data* — move the tag off the sentence if it breaks the voice.

## The test

Read the paragraph out loud. If it sounds like an ops brief, a research note, or a second copy of a table you already printed, rewrite it.

A local friend is sitting next to the reader. One idea per paragraph. Judgment first. Clocks and yen in the next paragraph. Tables support; they do not speak.

```
fact → one spoken sentence → clock / yen → table
```

## Do

- One idea per paragraph. Split walls.
- Human names first: shuttle week, station-bus week, rental-4WD week, eat-out week, inn-dinner week. Path A/B/C in parentheses once.
- Explain a term once, then use it: Happo Bus Terminal, Nagano Snow Shuttle, Hakuba Valley shuttle, Ideyu-go.
- Say a hard rule once, with why and the exception. Later: a short pointer (“wind day — skip Asahidake”).
- Back-door advice is *why locals go there* and *what inbound overpays* — not another Don’t list.
- Food: what to order, what to skip, how to book. Not “very strong reputation.”
- `[VERIFY 2026–27]` lives in a season box, a table footer, or after a number — not mid-clause.

## Do not

- Lead with Layer A / Layer B, knot, pin colour, egress, Act 2, HV, NSS as the reader’s vocabulary.
- Repeat the same Don’t in the 30-second table, the Don’t list, the body, the week table, and Book this.
- Leave research voice in the chapter: file paths, JMA block IDs, pH / mg/kg dumps, “operator-published testimonials.”
- Pack a paragraph into a table cell.
- Print the same restaurant list twice (master table *and* category table).
- Put Gumroad price or a repo path in the opening promise.
