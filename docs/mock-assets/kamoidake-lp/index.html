かもい岳の骨格

ここが違う

第1・第2がいまの営業核

リフト1本・東5本＋西・標高差50m——恐怖心を与えない「雪の箱庭」。富良野スキー場の混雑や長時間待ちを避け、空知の雲海を背景に静かに雪遊びを楽しむ隠れた名所（Hidden Gem）。

コース・ビューを見る

西パウダーは入場別

西は積雪次第で開放。西エリア入場券が別途必要で、第3リフトは運行しない。山頂へは東の第1リフト。戻りは開放日の無料シャトル。

Hands-free Package

手ぶらパッケージ、
到着時に受け取り。

施設内レンタルは現状なし——富良野エリアの民間レンタル事業者と連携し、事前オンライン決済でウェア・板をロッジ内またはロッカー受け取りにする「手ぶらパッケージ」提言（LP案）。

在庫リスクを施設が抱えず、海外からのお客様の受入を実現する外部連携モデル。
