Station Walk

駅から10分、
町民スキーへ。

JR天塩中川駅から徒歩10分（車3分）。案内板は少ないが、地元民に密着したひっそりとしたゲレンデ——「存在すら知らない」道北の隠れスキー場体験。

滑走後は天塩川温泉（音威子府村）や美深のびふか温泉へ——道北周遊の拠点として中川町を位置づける。
