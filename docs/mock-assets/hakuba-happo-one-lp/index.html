八方尾根の魅力

ここが違う

最長8kmのロングライド

総滑走面積220ha・16コース——スカイラインコースを含む国内屈指のスケール。山頂うさぎ平から北アルプス白馬三山を見渡す大パノラマの中、極上パウダーのロングクルーズを味わえます。

ゲレンデマップ

滑ったあと、八方温泉へ

pH11.5超の強アルカリ性単純温泉「八方の湯」「みみずくの湯」——滑走後のリカバリーと美肌ケアを、白馬エリアの湯めぐりで設計できます。

温泉特集を読む

付近の温泉

八方温泉と、
白馬の湯めぐり

八方尾根麓に「八方の湯」「みみずくの湯」「おびなたの湯」が点在——日本屈指の強アルカリ性美肌の湯として、スキー後の定番リカバリー拠点です。

夕方はジャンプ競技場見学やスノーピーク ランドステーション白馬と組み合わせ、エリア回遊の一日に。

  • 標高760〜1,831m・総滑走面積220ha——1月平均積雪210cm、2月240cmの安定した降雪環境。リーゼンスラロームやスカイラインなど、中上級者向けの看板コースが充実。

  • JR長野駅から車で約1時間4分——北陸新幹線ターミナルと組み合わせた週末スキーが現実的。長野駅でレンタカーを調達すれば、白馬エリアの広域周遊や温泉・グルメ回遊のハブになります。

    読む

  • 1998年長野オリンピックアルペンスキー競技会場——オリンピックコースI・II（最大35度）など競技コースが現役。2027年12月稼働予定の新10人乗りゴンドラ建設も進行中（公式要確認）。
