雫石の魅力

ここが違う

岩手山を望むプライベート・パウダー

21コース・標高差約702m——1993年世界選手権の舞台と非圧雪エリア。リフト待ちほぼゼロの「貸切感」で、極上の深雪を独占できます。

滑ったあと、雫石の食と湯へ

松ぼっくりのジェラート、雫石そば、盛岡冷麺の焼肉——ゲレンデを出れば、エリア回遊のグルメと網張温泉が待っています。

周辺グルメガイド

付近の温泉

網張温泉と、
雫石の湯めぐり

網張温泉ありね山荘から森の露天「ゆこたんの森」、プリンスホテル内の雫石高倉温泉まで——滑走後のリカバリーが設計しやすいエリアです。

プリンスホテル大浴場は設備が限定的という声も——帰路に網張の秘湯を組み込むのが定番です。

特集

特集ページ

  • 非圧雪エリアと雪上車（CAT）ツアーで、通常の索道では届かない極上パウダーへ。1993年世界選手権コースを滑れる「名門の物語」は、コアスキーヤーの承認欲求を満たすブランド価値です。

    読む

  • 東北自動車道・盛岡ICから車で約30分——東北新幹線盛岡駅と組み合わせ、レンタカーで雫石・盛岡市街・安比高原の広域周遊も可能です。

    読む

  • 小学生以下のリフト料金が全日無料——shiga-kogenスノーランドには動く歩道や雪遊びプログラムが充実。親はCATツアーでパウダー、子どもは安全な雪上体験という「親子分離型」滞在も設計できます。
