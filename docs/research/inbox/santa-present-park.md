# サンタプレゼントパーク・マロースゲレンデ 売上倍増戦略レポート

本レポートは、プロの観光マーケティングコンサルタントの視点から「サンタプレゼントパーク・マロースゲレンデ」の売上倍増に向けた具体的な戦略を提示するものである。なお、本レポートは情報提供を目的としたものであり、最終的な経営・投資判断を保証するものではない。

## Executive Summary

本ドキュメントは、旭川市街地から至近の都市型スノーフィールド「サンタプレゼントパーク・マロースゲレンデ」の売上を倍増させるための包括的な戦略インサイトである。

*   **現状とポジショニング:** 旭川市街地から車で約15分という圧倒的なアクセスの良さと、日本夜景遺産に認定された絶景ナイターを強みとする。一方で、規模の小ささ（標高差160m・6コース）や施設の老朽化が客単価・滞在時間の伸び悩みを生んでいる。
*   **強みと弱み:** 「市街地からの近さ」「夜景ナイター」「手ぶら利便性」が最大の武器である反面、昭和レトロ感が残る施設環境や、定番メニューに留まるゲレ食（ラーメン1,000円等）が、現代の付加価値を求めるインバウンドや若年層の不満の種となっている。
*   **競合環境:** 近隣の巨大山岳リゾート「カムイスキーリンクス」（全25コース・1日券5,300円）とは規模で圧倒的に劣後するため、真正面からの競合を避け、「都市型・短時間滞在・ナイター特化」というニッチ市場で独自の優位性を築く戦略が必須である。
*   **戦略の方向性とアクションプラン:** ゲレンデ単体での収益化から脱却し、周辺の強力な観光資源（高砂台エリアの温泉群や旭川ラーメン）と連携したエリア回遊モデル（「スキー×サウナ」のデジタルチケット化等）を構築する。さらに、OTA（アソビュー！等）を活用した販路拡大や、センターハウスのプチDX（コワーキング化）、中長期的には「ネオ・レトロ」へのリブランディングとグリーンシーズンの収益基盤確立によって客単価と稼働率を劇的に引き上げる。

## 1. 基礎データと現状のポジショニング

サンタプレゼントパーク・マロースゲレンデは、北海道旭川市神居町に位置し、地元旭川市民の「ちょい滑り」からファミリーの雪山デビュー、さらには訪日外国人観光客（インバウンド）まで幅広い層を受け入れるポテンシャルを持つ施設である [cite: 1, 2]。

その歴史は古く、1969年（昭和44年）に「旭川台場ヶ原サンバレースキー場」として開業し、1995年（平成7年）に現在の「サンタプレゼントパーク」へと名称変更、翌1996年には50億円規模のリニューアルを実施した背景を持つ [cite: 3]。ここでは施設の基本スペックと、現在の市場における立ち位置を整理する。

施設規模は標高差160mとコンパクトであるものの、変化に富んだコースと充実した設備が整っている [cite: 4, 5]。

*   **現地住所:** 〒070-8025 北海道旭川市神居町富岡555番地の2 [cite: 1, 6]
*   **連絡先:** 0166-63-3232 [cite: 1, 6]
*   **Google MAP:** [https://maps.google.com/?q=北海道旭川市神居町富岡555番地の2](https://maps.google.com/?q=北海道旭川市神居町富岡555番地の2)
*   **アクセス:** JR旭川駅から車で約15分、旭川空港から車で約40分、道央自動車道・旭川鷹栖ICから約15分（国道12号線経由） [cite: 6, 7, 8]
*   **営業時間:** 9:00～21:00（ナイター営業 16:00～21:00）※年末年始は短縮営業あり [cite: 4, 6]
*   **リフト料金体系:** 日中券（大人4,200円／小人3,300円）、ナイター券（大人1,800円／小人1,100円）、5時間券（大人3,600円／小人3,000円）、2時間券（大人3,000円／小人2,500円）など短時間滞在向けの券種も豊富に揃う [cite: 4, 6, 9]。※正確な最新料金はシーズンにより変動の可能性がある。

**コース構成と主要設備について**
山頂（トップ）の標高は330m、ベースは170mであり、全6本のコースが扇状に広がるレイアウトである [cite: 4, 5]。スノーボードW杯（国際スキー連盟主催）が過去に2回開催された実績を持つワイドバーンを有し、スキー（70%）とスノーボード（30%）の双方が滑走可能である [cite: 2, 5, 10]。
コースの難易度割合は初級40%、中級50%、上級10%となっている [cite: 4, 5]。具体的なコース展開は以下の通りである。

*   **スラロームバーン:** 全長800m、最大斜度25度（上級）。W杯などにも使用されるエキサイティングな急斜面 [cite: 5]。
*   **スノパラコース:** 全長600m、最大斜度25度（中級）。林間を縫うように走る変化に富んだコース [cite: 5]。
*   **ブラッキーコース:** 全長900m、最大斜度22度（中級） [cite: 5]。
*   **グリーンコース:** 全長700m、最大斜度23度（中級） [cite: 5]。
*   **登山道コース:** 全長1,000m、最大斜度22度（初級）。ゲレンデ最長のロングランが可能 [cite: 5]。
*   **センターコース:** 全長350m、最大斜度8度（初級）。ベース付近の緩斜面で初心者の練習に最適 [cite: 5]。
*   **キッズゲレンデ:** 独立したエリアが設けられており、ソリやスノースクートなど小さな子供でも安全に雪遊びが楽しめる [cite: 6, 11]。

輸送設備に関しては、ゴンドラやロープウェイは設置されておらず、ペアリフトが4基稼働している [cite: 4, 5, 7]。初心者や子供の乗車を補助するローディングカーペット（乗車用スノーエスカレーター）付きのリフトも完備されており、安全性への配慮が見られる [cite: 6, 12]。

現状のポジショニングとしては、広大なバックカントリーを求めるコアなパウダー層よりも、「手軽に・短時間で・美しい景色と共に」滑りたいライト層やファミリー層、さらには出張者やワーケーション層の仕事終わりのレジャー施設として、独自の都市型ニッチ市場を確立している。

## 2. 強みと弱み (内部環境)

売上倍増戦略を立案するにあたり、内部環境の棚卸しは不可欠である。本施設が持つ武器と、今後の成長を阻害し得る課題を明確にする。

**強み（Strengths）**
最大の武器は「立地」と「景観」の掛け合わせである。旭川市街地から車でわずか15分という至近距離にありながら、良質な雪質（パウダースノー）を体験できる点は特筆に値する [cite: 1, 4]。さらに、山頂のニコラス展望タワー（標高330m＋タワー50m）をはじめとするゲレンデ上部からの眺望は圧巻であり、2020年に「日本夜景遺産」に認定され、「恋人の聖地」にも選定されている [cite: 1, 10, 13]。ナイター営業時には、この宝石箱のような夜景に飛び込んでいくような独特の滑走体験が可能であり、他の山岳リゾートにはない圧倒的な独自性（USP：Unique Selling Proposition、独自の強み・価値提案）となっている [cite: 2, 8]。

また、設備面においては、手ぶらで利用可能な充実したレンタル用品が用意されている。大人用のスキー・スノーボードセットは1日4,500円（5時間4,000円、2時間3,500円）、ウェアは1日4,000円でレンタル可能であり、仕事帰りや観光の合間に手軽に立ち寄れる利便性を提供している [cite: 2, 4, 8, 14]。コース自体も幅広で整備が行き届いており、カービングターンの練習に最適であると上級者からの評価も高い [cite: 2, 15, 16]。

**弱み（Weaknesses）**
一方で、顧客体験を損ねる要因もいくつか見受けられる。まず、施設の規模が標高差160m、最長滑走距離1,000mと小規模であるため、丸1日滞在して滑り込むにはコースバリエーションが不足しており、滞在時間が短くなりがちである（客単価の伸び悩み要因） [cite: 4, 5]。また、ベースの標高が170mと低いため、近年の気候変動（暖冬）の影響を受けやすく、積雪量の確保やシーズン終盤の雪質維持にリスクを抱えている可能性が高い。

さらに、施設全体の雰囲気に対して「昭和のスキー場のよう」という口コミが散見される [cite: 17]。具体的な不満要素として、ゲレンデ内レストラン「キッチントント」のメニュー展開と価格設定が挙げられる。同レストランでは、しょう油・とんこつ・味噌ラーメンが各1,000円、カレーライス900円、カツカレー1,300円といった昔ながらの定番ゲレ食が提供されているが [cite: 18]、「価格の割に既製品のような味」といった厳しい口コミも存在している [cite: 19]。これはレトロでノスタルジックな魅力と捉えることもできるが、清潔でモダンな空間や「写真映え（インスタ映え）するおしゃれなカフェメニュー」など、付加価値の高い体験を期待する若年層やインバウンド客にとっては、顧客満足度を低下させるボトルネックとなっている恐れがある。

## 3. 競合比較

旭川エリアにおいて、サンタプレゼントパークの強力な競合となるのは、道北最大級の規模を誇る「カムイスキーリンクス」である [cite: 13]。

カムイスキーリンクスは旭川市内から車で約30〜40分の距離にあり、全25コース（最長滑走距離4,000m、最大傾斜35度）、広大なツリーランエリアや非圧雪のディープパウダーを特徴とする本格派の山岳リゾートである [cite: 13, 20, 21]。輸送設備としても、2名乗りリフト5基に加え、山頂まで約8分で到達する4人乗りゴンドラ1基を完備している [cite: 21]。リフト1日券は大人5,300円（シニア4,500円、小学生1,800円）に設定されており、丸1日スキーを満喫したい層や、パウダースノーを求める国内外のコアなスキーヤー・スノーボーダーを主ターゲットとしている [cite: 20, 22]。

**【競合比較表】サンタプレゼントパーク vs カムイスキーリンクス**

| 比較項目 | サンタプレゼントパーク | カムイスキーリンクス |
| :--- | :--- | :--- |
| **標高差 / 最長滑走距離** | 160m / 1,000m | 約600m以上 / 4,000m |
| **コース数 / 最大傾斜** | 6本 / 25度 | 25本 / 35度 |
| **リフト / ゴンドラ基数** | リフト4基 / ゴンドラなし | リフト5基 / ゴンドラ1基 |
| **リフト1日券（大人）** | 4,200円（日中券） | 5,300円 |
| **旭川市街からのアクセス** | 車で約15分 | 車で約30〜40分 |
| **ナイター営業** | あり（21:00まで・日本夜景遺産） | なし（日没まで） |
| **主要ターゲット層** | ライト層、ファミリー、ナイター需要、仕事帰り | コア層、パウダー志向、丸1日滞在 |

**競合に対する「劣後要因」**
サンタプレゼントパークは、規模感、コースの多彩さ、非圧雪エリアの広さ、そしてゴンドラ等の大型輸送設備において、カムイスキーリンクスに明確に劣後している [cite: 5, 13]。したがって、「パウダー・ツリーラン・広大な自然」を主目的とする顧客層を巡って真正面から競合と争う戦略は得策ではない。

**競合に対する「優位性」**
サンタプレゼントパークが勝る点は、「市街地からの圧倒的な近さ（15分）」と、「充実したナイター営業および夜景」である [cite: 1, 2]。カムイスキーリンクスは規模が大きい反面、移動に時間がかかり、日没後のナイター需要を満たす設計にはなっていない。
したがって、サンタプレゼントパークは「日中はカムイでパウダーを楽しみ、夜は旭川市街で食事をする」という観光客の動線に対して、「市街地で食事をする前に、美しい夜景を見ながら2時間だけナイターを楽しむ」あるいは「到着日や帰国日の空き時間に手ぶらでサクッと滑る」という、時間と場所の隙間を突くポジショニングで確固たる優位性を築くことができる。キッズゲレンデが独立している点も、ゲレンデデビューを控えたファミリー層への強いアピールポイントとなる [cite: 6, 11]。

## 4. ターゲット層のインサイト（口コミ分析）

各種レビューサイトやSNSに寄せられた顧客の声から、顕在的・潜在的なニーズを分析する。

**ポジティブな傾向**
*   **利便性と景観への絶賛:** 「仕事終わりにナイターで手ぶらでスノボに行けた」「ゲレンデから街の夜景が見られるなんて素敵」といった、都市隣接型ならではの機動力とロケーションが高く評価されている [cite: 8]。
*   **初心者に優しい設計:** 「キッズゲレンデが独立していて安心」「緩やかな斜面があり、初心者でも滑りやすい」と、ファミリー層や初学者の練習場としての信頼が厚い [cite: 11, 15]。
*   **玄人好みのバーン:** 「カービングの練習にもってこい」「しっかりと除雪（圧雪）されており滑りやすい」と、単なるファミリー向けにとどまらず、基礎スキーヤーやアルペンボーダーからの支持も獲得している [cite: 15, 16]。

**ネガティブな傾向と隠れたニーズ**
*   **施設のレトロ感とアップデート不足:** 前述の通り、「39年ぶりに行きましたがまるで昭和のスキー場でした」という声に代表されるように、施設やデザインの陳腐化を指摘する声がある [cite: 17]。高単価な食事メニューと質の乖離に対する不満は、「写真映え（インスタ映え）する空間やメニューが欲しい」「もっと快適な休憩スペースが欲しい」という潜在的欲求の裏返しである。
*   **刺激の不足:** 急斜面や長距離滑走を好む層にとっては、「数時間で飽きてしまう」という声なき不満がある可能性が高い。

これらのインサイトから、ハード面（コース）の満足度は高い一方で、ソフト面（飲食、休憩施設の雰囲気、イベント性）の拡充によって、若年層やカップル層の滞在価値をさらに高める余地があることが分かる。

## 5. 周辺観光資源とのシナジー（エリア回遊性）

サンタプレゼントパークの最大の弱点である「滞在時間の短さ（＝客単価の低さ）」を補うためには、ゲレンデ単体で収益を上げる発想から脱却し、旭川市内の豊富な周辺資源と連携した「エリア回遊性」の構築が必須である。

とくに車で数分〜10分圏内に位置する「高砂台（たかさごだい）エリア」は、旭川を代表する温浴施設の集積地であり、強力なシナジーを生み出すことができる。

**有望な周辺観光資源**
1.  **日帰り温浴施設（サウナ・スパ）:**
    *   **旭川 高砂温泉:** 昭和レトロな雰囲気が漂う「お風呂のデパート」。多様な湯船や屋上外気浴スペース、レトロゲームコーナーを備え、ファミリーからサウナ層まで楽しめる。日帰り入浴料金は大人平日午前600円、平日午後750円、土日祝850円とリーズナブルである [cite: 23, 24, 25, 26]。
    *   **旭川高砂台 万葉の湯:** 充実したアメニティと二股ラジウム温泉、リラクゼーションルームを完備したワンランク上の温浴施設。マル得セット入館料は大人1,800円であり、手ぶらで立ち寄れる利便性がスキー帰りとの相性抜群である [cite: 27, 28, 29, 30]。
    *   **杜のSPA 神楽:** 岩盤浴や天然石を用いたエキゾチックなスパリゾート。日帰り入浴料金は大人700円に設定されている [cite: 31, 32, 33, 34]。
2.  **旭川ご当地グルメ（ラーメン等）:**
    *   旭川ラーメンは醤油ベースにラードを浮かせた熱々のスープが特徴で、冷えた体を温めるのに最適である。近隣の神居エリアや旭川駅周辺には、「らーめん山頭火 旭川本店」「梅光軒 旭川本店」「蜂屋 五条創業店」などの世界的にも有名な老舗が密集している [cite: 35, 36, 37, 38, 39]。
3.  **周辺観光スポット:**
    *   行動展示で世界的知名度を誇る「旭川市旭山動物園」 [cite: 40]。
    *   天候に左右されない「旭川市科学館サイパル」や、美しい庭園「上野ファーム」 [cite: 40, 41]。

**回遊ルート構築案：「極寒パウダーからの熱狂トトノイ」ルート**
滞在時間と消費単価を上げるため、以下のような1Day/ハーフDayモデルルートを提案・発信する。
*   **午後スタート:** 旭川駅周辺のホテルを出発。手ぶらでサンタプレゼントパークへ直行し、16:00から暮れゆく旭川の絶景夜景をバックにナイター滑走を2時間満喫。
*   **夕方:** 車で10分の高砂台エリアへ移動。「高砂温泉」または「万葉の湯」で冷えた身体をサウナと温泉で徹底的に温める。
*   **夜:** 旭川駅周辺（さんろく街）へ戻り、熱々の旭川醤油ラーメンで締めるか、地元食材の居酒屋で消費を行う。
このように「スキー＋温泉＋ラーメン」のパッケージングを行うことで、ゲレンデ単体では得られない高単価な体験価値をエリア全体で創出できる。

## 6. 最新トレンドの適応可能性

社会的な最新トレンドをサンタプレゼントパークにどう組み込むか、その適応可能性を検証する。

**インバウンド（訪日外国人客）の取り込み**
正確なリアルタイムのインバウンド比率データは取得困難であるが、ニセコや富良野の混雑と高価格化を避けた外国人スキーヤーが、都市インフラが整い食事が安価で美味しい旭川エリア（旭川ステイ）に流れてきているトレンドがある。サンタプレゼントパークは「英語対応可能なレンタル・スクール」「市街地ホテルからのシャトルバス整備（現状の路線バス等の外国語案内強化）」を行うことで、「到着日のウォーミングアップゲレンデ」としてのインバウンド需要を確実に取り込める。

**通年化（グリーンシーズンの活用）**
夏期から初秋にかけては、山頂の「ニコラス展望タワー」が土日祝限定などで営業し、夜景スポットとして活用されている [cite: 40, 42]。しかし、タワー営業だけでは集客力が弱い。傾斜を活用したマウンテンバイク（MTB）のダウンヒルコースの整備や、見晴らしの良い斜面での「絶景ナイトグランピング・BBQ」、あるいは冬場のナイター照明設備を活用した「夜の昆虫採集イベント」など、グリーンシーズンの収益化に向けたアクティビティ導入の余地は極めて大きい。

**新規軸（ワーケーション、DX等）**
都市部から15分という近さは、ビジネス層の「ワーケーション」と親和性が高い。日中は市内のカフェやコワーキングスペース、あるいはゲレンデのセンターハウスにWi-Fiと電源を完備した「ワークスペース」でリモートワークを行い、16時の終業と同時に目の前のゲレンデでナイター滑走を楽しむ「エクストリーム・ワーケーション」のメッカとしてブランディングすることが可能である。また、リフト券の完全オンライン決済（QRゲート入場）等のDX（Digital Transformation：デジタル技術による業務・ビジネスモデルの変革）化を進めることで、人手不足の解消とインバウンドの利便性向上を同時に達成できる。

## 結論：売上倍増に向けたアクションプラン

ここまでの分析に基づき、サンタプレゼントパーク・マロースゲレンデの売上を倍増させるための現実的かつインパクトのある施策を提案する。

*   **短期アクション（1年以内で実行可能・即効性重視）**
    *   **「スキー×サウナ」パッケージチケットの販売:** 高砂台の温浴施設（高砂温泉、万葉の湯など）と提携し、リフト時間券と日帰り入浴券がセットになったデジタルチケットをアソビュー！、Webket、KlookなどのOTA（オンライン旅行代理店）等で販売する。アフタースキーの導線を仕組み化し、顧客単価を向上させる。
    *   **「夜景・ナイター特化型」のSNSマーケティング:** 「日本夜景遺産」×「ナイタースノーボード」のコントラストを強調したショート動画（Instagram Reels / TikTok）を多言語で配信。出張層やワーケーション層に向けた「仕事終わりの絶景手ぶらスキー」を訴求する。
    *   **センターハウスの「プチDX・コワーキング化」:** 大規模改修を待たずとも、既存の休憩所の一部に高速Wi-Fi、電源コンセント、適切な照明を導入し、「ゲレンデ・ワークスペース」として解放。平日日中のノマドワーカーやリモートワーカーを集客する。

*   **中長期アクション（1〜3年スパン・根本的な価値向上）**
    *   **「ネオ・レトロ」コンセプトへのリブランディング:** 「昭和感」という弱みを逆手に取り、あえてエモーショナルな「ネオ・レトロ」空間としてセンターハウスや看板をリデザインする。単なる既存メニュー（1,000円のラーメン等）から脱却し、クラフトビールや旭川の地元ロースターのコーヒーを提供するなど、若年層が「エモい」と感じる付加価値の高い空間設計に投資する。
    *   **グリーンシーズンの収益基盤確立（アドベンチャーツーリズム）:** ニコラス展望タワーを核とし、夏期のゲレンデ斜面を利用した「絶景バギー体験」や「ナイトグランピング・星空カフェ」を常設化。通年雇用と通年収益のサイクルを回す。
    *   **多言語シャトル＆手ぶらVIPプランの創設:** 旭川市内の主要ホテルとゲレンデをダイレクトに結ぶ外国人向けの直行シャトルバスを運行。同時に、ハイエンドウェアと最新ギアのレンタル、プライベートレッスンを含めた「インバウンド向け高単価VIPパッケージ」を構築し、富裕層の隙間時間をマネタイズする。
