5.2b 八方BT発 — ゲレンデ別シャトル早見（路線・料金・払い方）

八方バスターミナル（八方BT）は、HAKUBA VALLEY 内シャトルの最大ハブ。行き先ごとに 無料のスキー場シャトル（Line H / E / I / T / F / G / N / R / O 等）と、 有料の広域 Line V（HVパス所持で無料）が並ぶ。時刻・停車はシーズンで変わるため、出発前に公式を確認すること。

一次ソース: HV シャトルバス（日本語） · Shuttlebus (EN) · 八方村内シャトル · 運行例: 2025-12 〜 2026-03 頃（年度により前後）

乗り方（車なし・八方BT起点）

  1. 宿から八方BTへ徒歩（THE HAPPO なら約3分）。スキー板・ボードはバス規定に従って持つ／ラックへ。
  2. 行き先の Line 表示（車体・電光・時刻表PDF）を確認。同じBTでも乗り場が分かれることがある。
  3. HVパス／Day Passがある日は、無料スキー場シャトル優先。無い日に Line V に乗るなら、 乗車前にオンラインでバス券（現金は使えない）。
  4. ハイシーズン朝（おおむね 8:00–9:30）は満員・積み残しあり。特に北部（コルチナ／乗鞍／栂池方面）は始発の20分前に列へ。
  5. 夕方〜最終便も混雑。ゲレンデ発の帰りの列も早めに。
