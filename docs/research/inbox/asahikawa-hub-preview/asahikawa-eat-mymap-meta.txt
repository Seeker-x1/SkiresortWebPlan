公開設定（リンクを開くと「アクセス許可」を求められるとき）
================================================================================
原因: 地図が「制限付き」（特定 Google アカウントのみ）のまま。

手順（地図を開いた状態で）:
1. 右上 **共有**（Share）をクリック
2. **一般的なアクセス**（General access）を **制限付き** → **リンクを知っている全員** に変更
3. 権限は **閲覧者**（Viewer）。編集者にしない
4. **完了** → 表示されている viewer URL をコピー（mid= が同じか確認）
5. 別ブラウザ or ログアウト状態で viewer URL を開き、ログイン不要で地図が見えるか確認

まだログイン画面になる場合:
- 共有ダイアログを再度開き、リンクを知っている全員が本当に ON か確認
- 会社 Google Workspace で外部共有がブロックされていないか確認
- 一度 **ファイル → 新しい地図にコピーを作成** → 新コピーで上と同じ公開 → 章の mid= URL を差し替え

※ Yuzawa drive map メモと同じ: viewer がログインに落ちるあいだは Share → リンクを知っている全員が見られる。

================================================================================
インポートで「匿名でのインポートはできません」
================================================================================
CSV の中身が悪いのではなく、**Google があなたをログイン済みユーザーとして認識していない**ときに出ます。

よくある原因:
1. **viewer URL** で開いている（閲覧専用）。**edit URL** で開くこと
2. **ログインしていない** / ゲスト / シークレット / 別アカウント
3. **地図のオーナーではない** Google アカウントで編集を試している
4. ブラウザの **Cookie・セッション不調**（2026年頃、My Maps で多発報告）

手順（この順で試す）:
1. Chrome（推奨）で **edit URL** を開く:
   https://www.google.com/maps/d/edit?mid=1H9fAIBhcInblW99U2jBObN4dOxJ_2G4
2. 右上アイコンで **地図を作った Google アカウント** に切り替え
3. 別タブで https://sheets.google.com を開き、同アカウントでログイン確認
4. My Maps に戻り、左レイヤー **インポート** → CSV を選択（ドラッグでも可）
5. まだ失敗 → 一度ログアウトして再ログイン / Cookie 削除 / Edge 試行
6. 代替: CSV を **Google ドライブにアップロード** → My Maps のインポートで Drive から選択

viewer で「アクセス許可」を求められる件と、匿名インポートは別問題:
- 閲覧の公開 = 共有設定
- インポート = 必ず **オーナーアカウント + edit 画面 + ログイン状態**
